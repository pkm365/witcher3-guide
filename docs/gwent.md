# 昆特牌全收集

「卡牌收藏家」（取得基础版本全部昆特牌）是 78 个成就里最容易永久错过的一个。记住三条：**逢人就打、商人的卡全买、任务窗口里的卡当场拿**。

## 易错过卡清单（按时间顺序）

1. **白果园旅店这一组**（序章）：老板娘 Elsa 的 5 张卡（诱饵、克林菲德掠夺者龙猎人、投石机、蓝衣铁卫突击队、弗尔泰斯特「北方领主」）要在主线完成前买；学者打赢拿卓尔坦卡。漏了有兜底（商人 Bram 补卖、吊死鬼之树拾取），但当场拿最稳。诱饵是实用牌，老板娘处反复进商店最多可买 3 张。
2. **各地旅店老板与商人**：每到一个新村镇，先去酒馆和商人处把卖的卡买光、牌局打赢。个别老板会随主线推进死亡或离开（如诺维格瑞翠鸟酒馆的奥利维尔，在特莉丝撤离线推进前处理完）。
3. **血腥男爵**：威伦主线推进前打赢他（他会离开乌鸦窝）。
4. **「生命诚可贵」派对三连局**（诺维格瑞，特莉丝线）：化装舞会上三位宾客各有一张卡，**必须当场连赢三局**，离开派对永久错过。
5. **「危险游戏」奖励选卡**（卓尔坦线）：任务结尾选拿卡牌，不要金币。
6. **「致命阴谋」后续 · 泰勒**：刺杀线推进后，在七只猫酒馆赢下泰勒的英雄卡。
7. **高风险大赛（帕西佛罗拉）**：「昆特牌大师」+ 数张对手卡都在这里。要求牌组里有足够多的单位牌才能报名；**中途输一局任务直接失败、卡永久错过**——进场前手动存档，牌组强度不够就先去补卡。
8. **史凯利格牌局**：继位线相关人物（如疯子卢戈等人）的卡要在其剧情窗口内打。

## 收集习惯

- 告示板、铁匠、商人、旅店老板，图标是人的都点一遍对话，看到「来局昆特牌吗」一律打。
- 买卡不贵：商人卖的卡全买下来也就几百克朗，别省。
- 牌组路线：北方领域起家最稳（免费抽牌 + 号角），攒英雄牌后「尽遣王牌」（一局 3 张英雄牌获胜）和「杰洛特与朋友们」（只用中立牌获胜）后期自然能刷。

## 血与酒：史凯利格牌组

- 成就「昆特成瘾」要求集齐**史凯利格牌组**全部卡（新牌组，陶森特各地牌局 + 任务发放）。
- 陶森特的牌局对手分布在各酒馆和庄园，推进血与酒时顺手清；大赛（陶森特昆特大赛）在牌组齐后参加。
- 「大获全胜」（石之心成就）：以 187+ 总战力赢一局——后期用史凯利格/北方满配牌组叠 buff 即可。
