# 毕业装备路线

## 阶段路线

| 阶段 | 武器 | 防具 | 说明 |
|---|---|---|---|
| 开局（白果园） | 毒蛇学派钢剑 + 银剑 | 任意 | 图纸在白果园，序章最好的双剑 |
| 前期（约 11 级起） | 狮鹫学派套装武器 | 狮鹫套（法印流）/ 猫套（剑术流） | 寻宝任务拿图纸，铁匠打造；穿满一套解锁「全副武装」 |
| 中期 | 高等 → 大师级学派装备 | 同学派升级 | 图纸分四档：基础 → 强化 → 高等 → 大师，一档档往上做 |
| 石之心 | 蝮蛇学派双剑 | 蝮蛇套 | 图纸在拍卖会与任务流程中，易错过，见路线页提醒 |
| 血与酒（毕业） | **湖女之剑**（银剑）+ **陶森特骑士钢剑**（钢剑） | **宗师级学派套**一套 | 见下方毕业清单 |

## 流派怎么选（强度向）

- **炼金流（最稳，推荐）**：宗师螳螂妖套 + 突变「欣喜若狂」（Euphoria）。煎药 + 魔药叠满后伤害和容错都拉满，高难度下也是主流答案，也顺手解锁「醉生梦死」（7 种药剂同时生效）。
- **法印流**：宗师狮鹫套，阿尔德/伊格尼范围和强度成型，清群快，「失足致死」「环境危害」刷起来顺手。
- **剑术流**：宗师猫套（轻甲暴击）或狼套（均衡），手感最好，容错相对最低。
- **坦克流**：宗师熊套 + 昆恩，硬吃伤害，适合稳扎稳打。

选一套宗师做满即可；「终极收集狂」只要求**图纸**集齐 5 套宗师（猫、狮鹫、熊、狼、螳螂妖），不用全打造出来。「人要衣装」要求穿着成套宗师装备触发套装加成（3 件/6 件）。

## 毕业双剑

- **银剑 · 湖女之剑（Aerondight）**：全游戏最强银剑，连续命中积攒充能，满充能击杀永久提升伤害，越用越强。获取条件：攒齐**五德**后在湖中女神任务中领取（成就「五德化身」）。
- **钢剑 · 陶森特骑士钢剑**：铁匠打造（宗师级铁匠在陶森特），高暴击高爆伤，钢剑毕业装。备选： Gesheft（陶森特寻宝/任务获取）。

## 五德对照（湖女之剑）

五种美德各有多次示范机会，原则对了就不会漏；每德错过一次还有下一次，但别整德全错。

| 美德 | 行为原则 | 典型机会 |
|---|---|---|
| 慷慨 | 该给钱时别讨价还价 | 陶森特送信的小男孩，给他小费 |
| 同情 | 能放过/解咒就别杀 | 被诅咒的匙魔：选择解除诅咒 |
| 英勇 | 接受挑战、不临阵退缩 | 骑士比武大赛出战并取胜 |
| 荣誉 | 信守承诺、拒绝收买与作弊 | 比武与骑士任务中堂堂正正 |
| 智慧 | 先调查、先讲道理再动手 | 委托中查明真相而非一律砍杀 |

集齐后去陶森特的湖中岛触发湖中女神的考验，通过即得。

## 附魔与细节

- 血与酒的附魔师（Runewright 在石之心开启）给胸甲上「保护」/武器上 Severance（延长剑气）等，按流派选。
- 马具：欧菲尔马具（石之心，成就「独领风骚」需要整套欧菲尔装备含马具）、陶森特骑士马具（比武大赛奖励）。
