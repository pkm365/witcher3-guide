## 一周目全成就的五个铁律

1. **难度成就先放一边**（已定）：两个难度通关成就（想流点血以上 / 死而无愧）这一轮先不追，安心享受一周目；之后想补，再议二周目或重开的事。其余 76 个成就的路线不受影响。
2. **昆特牌从第一天就打**：「卡牌收藏家」是全游戏最容易翻车的成就——多张卡只在特定任务窗口出现，错过无法补。见 [昆特牌全收集](/gwent)。
3. **两个 DLC 各有一处互斥，先存档再抉择**：石之心的最终抉择（帮奥吉尔德还是放任镜子大师）、血与酒的结局走向（勋章结局 vs 入狱结局），抉择前手动存档，分两路各拿一个成就。
4. **刷量成就早开工**：弩箭爆头人类 50 个、亚克席傀儡杀人 20 次、阿尔德震落摔死 10 个……这些靠全程顺手攒，拖到后期再刷很痛苦。
5. **顺序 = 本体 → 石之心 → 血与酒**：等级曲线、装备图纸和剧情体验都按这个顺序最顺，血与酒的宗师套装和突变系统是毕业终点。
